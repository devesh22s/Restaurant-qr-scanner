# 🍽️ Restaurant QR Scanner  
A modern full-stack application that allows customers to scan a QR code on the table and instantly view the restaurant menu online.  
Built with **React (client)** and **Node.js + Express (server)**.

---

## 🚀 Live Demo  
🔗 **Production URL:** https://restaurant-qr-scanner.vercel.app/

---

## 📂 Project Structure  
```
/
├── client    -> React frontend
├── server    -> Node.js + Express backend
└── .gitignore
```

---

## ✨ Features  
- 📱 Scan QR Code to open menu instantly  
- 🍔 View food items with image, price, and details  
- ⚡ Fast & responsive UI  
- 🔒 Secure backend APIs  
- 🌐 Fully deployed on Vercel  

---

## 📦 Installation & Setup  

### **1️⃣ Clone the repo**
```bash
git clone https://github.com/devesh22s/Restaurant-qr-scanner.git
cd Restaurant-qr-scanner
```

---

## 🖥️ Start Frontend  
```
cd client
npm install
npm run dev   # or npm start
```

---

## 🛠️ Start Backend  
```
cd server
npm install
npm start
```

---

## 🔗 API Endpoints (Example)
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/menu | Fetch menu items |
| POST | /api/order | Create new order |

---

## 🧩 Environment Variables  
Create a `.env` file inside **server/**:

```
MONGO_URI=your_mongodb_url
PORT=3000
JWT_SECRET=your_secret
```
